Installing Hermes Agent Locally

▶ 1:30

David walks through the full local installation of Hermes Agent. The process works identically on a local machine or a VPS.

Step-by-step:

  1. Go to the Hermes Agent GitHub repository.
  2. Scroll down to the "Quick Install" section and copy the one-liner install command.
  3. Open a terminal and paste the command. This installs Hermes Agent on your machine.
  4. Once installed, run hermes setup to launch the interactive setup wizard.

Choosing a Provider (OpenRouter)

▶ 2:30

The setup wizard asks which LLM provider to use. David selects OpenRouter:

  • Go to openrouter.ai and create an account (~20 seconds).
  • Navigate to the top-right corner → Credits → add funds ($5–$10 is plenty).
  • Go to API Keys → "New Key" → name it, set a spending limit (~$50 as a precaution), and copy the key.

Configuring the Model

▶ 4:00

Back in the terminal:

  • Select OpenRouter as the provider and paste the API key.
  • Choose a model — David picks Claude Opus 4.7 (the latest at time of recording).
  • Fallback credential: Not needed, skip with "No."
  • For remaining settings (text-to-speech, iterations, navigation platform, CLI options), David recommends keeping the defaults — just press Enter through them.

First Launch & Test

Installing Vapi MCP in Hermes

▶ 14:00

This is the key integration step — connecting Hermes to Vapi via the Model Context Protocol (MCP).

Step-by-step:

  1. In the Hermes terminal, install the Vapi MCP server. This is a single command — David shows the exact install command.
  2. The MCP server acts as a bridge: Hermes can now invoke Vapi's telephony capabilities as tools.
  3. Configure the MCP connection by providing:
    • Your Vapi API key
    • Your purchased phone number
    • Any default settings (voice, language, etc.)

Creating a Voice Agent / Assistant in Vapi

▶ 18:00

With the MCP connected, David sets up a voice agent (assistant) inside Vapi's dashboard. This defines how the AI sounds and behaves on the phone.

Key configuration steps:

  1. Go to the Vapi dashboard → Assistants → Create New.
  2. Choose a voice — Vapi offers multiple text-to-speech providers with natural-sounding voices.
  3. Set the system prompt / personality for the voice agent:
    • How it should introduce itself
    • What information it should collect
    • How it should handle objections or questions
  4. Configure the assistant's behavior:
    • First message (what it says when the call connects)
    • End-of-call behavior (summary, transcript logging)
    • Interruption handling (how it deals with being interrupted mid-sentence)

Linking the Assistant to Your Phone Number

▶ 20:00
  • Assign the newly created assistant to your purchased phone number.
  • This means inbound calls to that number will be handled by the voice agent.
  • For outbound calls, Hermes will specify which assistant to use when initiating a call via the MCP tools.

Cron Jobs — Proactive Autonomous Calling

▶ 26:00

David takes the setup to the next level by introducing cron jobs — scheduled tasks that let Hermes operate completely autonomously.

How it works:

  • Hermes Agent has built-in cron job support (scheduled tasks that run at specified times).
  • You can configure Hermes to, for example:
    • Every morning at 9 AM, research 10 new leads in your target market.
    • Every afternoon at 2 PM, call the researched leads.
    • Every evening at 6 PM, compile a summary report and call you with results.

Setting Up a Cron Schedule

▶ 27:30
  • David demonstrates creating a cron job within Hermes.
  • The cron configuration includes:
    • Schedule (time and frequency)
    • Task description (what Hermes should do)
    • Success criteria (how to evaluate if the task was completed)
  • Once set, Hermes runs these tasks proactively without any human trigger.

  • For business users, this means automated lead generation and outreach running 24/7.
  • For personal users, this means never having to make a boring phone call again.
