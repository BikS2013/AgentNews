1 The Paradigm Shift: From Web Apps to MCP Apps ▶ 0:00

AI is fundamentally changing how users discover and interact with services. Rather than visiting websites directly, more and more people are using chatbots for their routine searches and research. This trend is giving rise to MCP apps — instead of returning plain JSON or markdown, services now provide interactive, helpful widgets rendered directly inside a chatbot interface.

Alpic recently released Skybridge, an open-source TypeScript framework that makes it easy to create custom MCP apps for all sorts of use cases. The video walks through what Skybridge is, how it works, and builds a working app from scratch.

Key insight: "Instead of spitting out a JSON file or a markdown document, more apps and services are switching to providing these interactive and helpful widgets inside a chatbot."

2 How MCP Apps Work: Two Users, One Interface ▶ 0:47

Traditional web apps are built for one user: the human. MCP apps are fundamentally different — they're built for two users at once: the human and the AI assistant. Both share the exact same interface.

  • Human interaction — the user clicks buttons, types inputs, and slides sliders. The LLM instantly sees the updated state.
  • AI interaction — the LLM can update data in the background, and the UI changes in real time right in front of the user.
  • Bidirectional state sync — Skybridge handles all the complex plumbing: protocol bridging, state synchronization, and security rules.

This means developers just focus on writing standard React code, while Skybridge takes care of making it work seamlessly for both humans and AI.

Key insight: "With an MCP app, you're actually building for two users at once — the human and the AI assistant — because they both share the exact same interface."

3 The Dev Experience Problem (and How Skybridge 1.0 Solves It) ▶ 1:35

Building MCP apps for ChatGPT or Claude used to involve a painful local testing loop: manually setting up public tunnels, copy-pasting configurations, and restarting chat sessions just to fix a tiny CSS typo.

Skybridge 1.0 completely redesigned the developer tools control panel. When you run your local dev server, it fires up an emulator dashboard in your browser with three key tools:

  1. Alpic Playground — a local sandbox where you can test your tools and tweak React widgets using live hot module replacement (HMR). See changes instantly without touching an actual LLM.
  2. Integrated Tunnel — with a single click, expose your local server through a secure public URL. No more messing around with external tunneling tools. Just paste the URL into ChatGPT's developer settings and you're live.
  3. Beacon Audit Tool — scans your app's metadata, tools, and security policies to catch common rejection triggers before you submit to public app stores.
Key insight: The three-tool developer dashboard (Playground + Tunnel + Audit) eliminates the biggest friction points in MCP app development — no more external tunnel setup, no more blind LLM testing, no more surprise app store rejections.

Even if you've never built an MCP app, you can get started instantly by installing the Skybridge skill onto your favorite AI agent (like Claude Code). The skill can be installed globally or scoped to a specific repository.

The demo starts with a pre-built React e-commerce website for camera lenses — a fully functional store with cart and checkout functionality. The goal: add an MCP app so that when a customer searches for lens recommendations in a chatbot, it calls the store's MCP app and shows product listings interactively.

6 Testing in the Developer Dashboard ▶ 4:24

The developer dashboard shows the generated tools — in this case, a Search Lenses tool and a Place Order tool. Andres demonstrates the full flow:

  • Search — set a max price ($2,000), limit to 5 results. The tool finds 14 matching lenses.
  • Preview modes — desktop view, mobile view, dark mode, and light mode are all available.
  • Live state sync — selecting lenses updates the tool output and state on the fly. The state panel shows real-time changes as the user interacts.
  • Compare — select three lenses, click compare, and see them side by side with all parameters.
  • Checkout — move to checkout, fill in name, email, shipping address, and place the order — all within the dashboard.
Key insight: The Skybridge dashboard lets you test every aspect of your MCP app — search, selection, comparison, checkout — without ever connecting to an actual LLM. This dramatically speeds up the development loop.

7 Connecting to Claude (Live LLM Integration) ▶ 6:07

Once the app works in the dashboard, connecting it to a real LLM is straightforward:

  1. Activate the tunnel in the developer dashboard to get a secure public URL.
  2. In Claude settings, go to the Connectors section and click Customize.
  3. Add a custom connector — give it a name and paste the tunnel URL.
  4. Click Connect — optionally set permissions for automatic tool execution or require user approval.
  5. Start a new chat and ask: "Give me some recommendations for the best lenses under $2,000 for portrait shooting."

Claude immediately recognizes the MCP app, searches the lens shop catalog, and renders the interactive widget directly in the chat. Users can select lenses, compare them side by side, and proceed to checkout — all without leaving the conversation.

Andres notes one minor CSS issue: white space from a previous tool state. This is easily fixable in CSS and doesn't affect functionality.

8 App Store Readiness: The Beacon Audit ▶ 7:57

Before submitting an MCP app to public app stores, you can run an audit through the developer dashboard. The Beacon audit tool scans your app's metadata, tools, and security policies to identify issues that could trigger rejection during review.

This is especially valuable because app store review criteria for MCP apps are still evolving, and common mistakes (missing metadata, overly broad permissions, security policy gaps) can lead to frustrating back-and-forth rejections.
