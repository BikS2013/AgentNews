2 Local Installation & First Session ▶ 1:00

David walks through installing tmux locally on macOS and the fundamental workflow of creating, detaching, and reattaching sessions.

  • Install — brew install tmux on macOS. For other platforms, ask ChatGPT or Claude for the equivalent command.
  • Verify — tmux -V to check the installed version
  • Create a session — tmux new -s <name> — the green bar at the bottom confirms you're inside tmux
  • Detach — Ctrl+B then D — session keeps running in the background
  • Reattach — tmux attach -t <name> — reconnect to the running session
  • List sessions — tmux ls — shows all active sessions
  • Exit — type exit inside the session to close it
Key insight: The magic — you can run a command (like ping google.com), detach with Ctrl+B D, do other work, then reattach and find it still running.

3 Building Blocks — Sessions, Windows, Panes ▶ 3:06

David explains the three essential building blocks of tmux and why they matter for multi-agent setups.

  • Session — the whole workspace. Wraps everything. Named for easy reference.
  • Window — like tabs in a browser. Multiple windows inside a session.
  • Pane — split screens inside a single window. Each pane is a separate terminal.
  • Why this matters for agents — tmux can persist, spawn, read, and write terminal sessions programmatically. This means agents can read what other agents are doing in other panes — impossible with separate terminal windows.
Key insight: "tmux is the substrate that the whole multi-agent setup stands on. Agents can see what other agents are doing if they need to."

5 SSH into VPS & tmux Setup ▶ 5:37

David shows the step-by-step process of SSHing into the VPS and configuring tmux for comfortable use.

  • SSH in — copy the SSH command from your hosting panel, paste in terminal, enter root password
  • Check tmux — tmux -V (often pre-installed on Ubuntu VPS)
  • Install if needed — apt update && apt install tmux
  • Enable mouse support (non-negotiable) — echo "set -g mouse on" >> ~/.tmux.conf. Without this, you can't scroll, can't click between panes, and have to use keyboard shortcuts for everything.
  • Create first session — tmux new -s agents
Key insight: "You need to enable mouse support. Without that, you cannot scroll in tmux. You have to do everything by hand."

6 Splitting Panes — The Multiplexing Magic ▶ 7:37

David demonstrates splitting tmux panes to run multiple terminals simultaneously — the foundation for multi-agent setups.

  • Horizontal split — Ctrl+B then % (percent sign)
  • Vertical split — Ctrl+B then " (quotation mark)
  • Important gotcha — it's Ctrl+B, release, then the key. NOT Ctrl+B+% simultaneously.
  • Mouse support — with mouse enabled, you can click between panes and resize them by dragging
  • Exit a pane — type exit to close individual panes
  • Kill everything — tmux kill-server destroys all sessions at once

🎯 Key Takeaways

  1. tmux is non-negotiable for agentic engineering — it's a terminal multiplexer that keeps sessions alive when you disconnect. Essential for long-running AI agents.
  2. Sessions, windows, panes — three building blocks. Sessions wrap everything, windows are like browser tabs, panes are split screens. Agents can read other panes programmatically.
  3. Core commands — tmux new -s name (create), Ctrl+B D (detach), tmux attach -t name (reattach), tmux ls (list), tmux kill-server (destroy all).
  4. Splitting panes — Ctrl+B % (horizontal), Ctrl+B " (vertical). Remember: press Ctrl+B, release, THEN press the key.
  5. Enable mouse support first — echo "set -g mouse on" >> ~/.tmux.conf. Without it, you can't scroll or click between panes.
  6. VPS + tmux is the real power — run agents on a VPS, SSH from any device. Your MacBook's battery, memory, and uptime no longer matter.
  7. Session persistence survives SSH disconnects — kill your connection entirely, reconnect, tmux ls — sessions are still running. This is proven live in the video.
  8. Multi-agent setup — run Claude Code, Codex CLI, and other agents in separate tmux panes on the same VPS, each working on different features or projects.
  9. /go and /goal for autonomous work — give an agent a long-running goal, detach from tmux, and let it work for hours or days while you do other things.
  10. Mobile SSH with Terminus — manage your running agents from your iPhone when you're away from your computer.
  11. SSH tunneling for preview — forward ports from VPS to localhost to preview apps being built by agents in your local browser.
  12. Setup takes 40-60 minutes — VPS + tmux + Claude Code + Codex CLI. Once set up, it puts you ahead of "99.9% of people" who are still developing locally.
